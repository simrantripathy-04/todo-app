# To-Do Application

A full-stack To-Do application built with React.js, Node.js, Express.js, and MongoDB, featuring task creation, updating, deletion, and efficient task management.

## Features

- Create tasks
- Update tasks
- Delete tasks
- View and manage tasks
- Responsive user interface
- RESTful API integration
- MongoDB database integration

## Technologies Used

- React.js
- JavaScript
- Node.js
- Express.js
- MongoDB
- Git & GitHub
